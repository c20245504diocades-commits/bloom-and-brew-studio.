# Bloom & Brew Studio

A responsive studio website for Bloom & Brew Studio, built with semantic HTML, Tailwind CSS, and GSAP.

## Features

- Semantic HTML structure
- Tailwind CSS design system with custom color tokens
- Reusable button, card, and form-field component classes
- Responsive mobile-first layout
- Dark mode with saved user preference
- GSAP page-load animation
- GSAP ScrollTrigger section reveals
- Scroll progress bar
- Contact form layout

## Run locally

Open `index.html` in a web browser.

## Technologies

- HTML
- Tailwind CSS v4 Browser CDN
- GSAP
- GSAP ScrollTrigger
